# 👋 Intro
안녕하세요. 광고 자동화, 이커머스, 의료·뷰티 플랫폼을 개발해 온 약 5년 경력의 백엔드 중심 풀스택 개발자 안민성입니다.<br>
Laravel과 CodeIgniter 기반 실무에서 요구사항 분석, 데이터베이스·API 설계, 관리자 시스템 개발, 외부 API 연동, 배포와 운영까지 수행했습니다.<br>
React와 Next.js 프론트엔드 경험을 바탕으로 화면, API와 데이터 흐름을 하나의 시스템 관점에서 판단하며, 최근에는 Java·Spring Boot 기반 프로젝트로 백엔드 역량을 확장하고 있습니다.<br>
기능 구현에 그치지 않고 데이터 정합성, 운영 안정성과 유지보수성을 함께 고려하는 개발을 지향합니다.<br><br>
